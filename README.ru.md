# HzPilot

HzPilot - лёгкая утилита для Windows, которая переключает частоту обновления монитора без открытия системных параметров.

[English version](README.md)

## Возможности

- Показывает все активные мониторы и частоты, доступные в драйвере.
- Меняет только частоту, сохраняя разрешение, ориентацию, глубину цвета и расположение экранов.
- Проверяет режим средствами Windows перед применением.
- Работает с несколькими мониторами и зеркальными группами дисплеев.
- Восстанавливает значок после перезапуска Проводника.
- Поддерживает автозапуск для текущего пользователя без прав администратора.
- Интерфейс на русском и английском языке.
- Без телеметрии, сети, фоновой службы и отдельного runtime.

## Требования

- Windows 10 версии 1809 или новее либо Windows 11.
- Процессор x64.
- Драйвер, предоставляющий несколько частот для текущего разрешения.

## Использование

1. Запустите `HzPilot.exe`.
2. Нажмите левой кнопкой на значок в трее.
3. Выберите монитор и поддерживаемую частоту.
4. Нажмите правой кнопкой для управления автозапуском, открытия параметров Windows или выхода.

Windows сначала помещает новые значки в скрытую область трея. Закрепить HzPilot рядом с часами может только пользователь.

## Безопасность

HzPilot получает совместимые режимы через `EnumDisplaySettingsExW`, оставляет только варианты для текущего разрешения, проверяет выбор через `CDS_TEST` и лишь затем вызывает `ChangeDisplaySettingsExW`. Пользовательские и RAW-режимы не предлагаются.

Программа управляет фиксированными частотами. Dynamic Refresh Rate в Windows 11 определяется и отображается, но выбор числового значения включает фиксированную частоту. Remote Desktop и некоторые виртуальные драйверы могут не предоставлять переключаемые режимы.

## Установка

В релизах публикуются:

- `HzPilot-<version>-windows-x64.zip` для портативного запуска.
- `HzPilot-<version>-setup-x64.exe` для установки в `%LOCALAPPDATA%\Programs\HzPilot` без UAC.

Неподписанные тестовые сборки могут вызывать предупреждение Microsoft Defender SmartScreen. Подпись планируется до стабильного релиза.

## Сборка

Понадобятся Rust 1.85 или новее, target `x86_64-pc-windows-msvc`, Visual Studio Build Tools и Windows SDK с `rc.exe`.

```powershell
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test
cargo build --release
```

Программа использует Rust и прямые вызовы Win32 без UI-фреймворка. После изменения рисунка иконки запустите `tools/generate-icon.ps1`.

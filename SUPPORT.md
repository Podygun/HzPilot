# Support

## Questions and troubleshooting

Use [GitHub Discussions](https://github.com/Podygun/HzPilot/discussions) for setup questions, hardware compatibility, and general troubleshooting.

Before asking for help, include:

- Windows edition and version.
- GPU model and driver version.
- Monitor model, connection type, and topology.
- Current resolution and refresh rate.
- Whether the session is local, Remote Desktop, or virtualized.

## Bugs

Use the structured [bug report form](https://github.com/Podygun/HzPilot/issues/new/choose) for reproducible defects.

## Security

Do not open public issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md) instead.
